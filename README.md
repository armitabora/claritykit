# ClarityKit — Find the fine print

ClarityKit turns long opportunity notices (hackathons, scholarships, internships, grants, and similar calls) into a readable list of possible deadlines, eligibility terms, deliverables, restrictions, build requirements, judging criteria, and prize language.

**Core principle:** every finding is accompanied by source wording. ClarityKit does not silently invent an answer or claim that it has proved eligibility.

## Features

- Evidence log: keyword-based category matches show the original sentence or line that triggered the match.
- Date radar: surfaces common written date formats and gives a rough date-distance label when parsing succeeds. It does not assume every date is a deadline.
- Eligibility, deliverables, restrictions, build rules, judging and prize categories.
- Review prompts for topics that were not matched clearly. These prompts do not assert that a topic is absent from the notice.
- Interactive checklist with progress indicator.
- Filter findings by category.
- Export findings and spotted dates to CSV; copy a plain-text summary.
- Responsive layout and explicit limitations so users can verify the official source.
- No paid API key and no external AI API call required.

## Run locally

Requires Python 3.10 or newer.

```bash
python -m venv .venv
source .venv/bin/activate        # macOS / Linux
# On Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

On macOS, double-click `RUN_CLARITYKIT.command` (right-click → Open if Gatekeeper asks). Or run the commands above and open <http://127.0.0.1:5000> in your browser. Click **Load sample notice**, then **Analyze notice**, or paste your own official notice.

## Run tests

```bash
python -m unittest discover -s tests -v
```

## Important limitations

- Extraction uses keyword rules and common date patterns, not a language model. It may miss paraphrases, context, nested bullets, dates in unusual formats, or rules expressed indirectly.
- A sentence may match a category even when it is not a strict requirement. The original quote is shown so users can judge it.
- Parsed date proximity is based on the computer/server's current date; it does not robustly interpret time zones or every time format.
- This is not legal, financial, or official eligibility advice. Always confirm all findings, dates, prize conditions, and rules on the authoritative source.
- Do not paste confidential information, passwords, access tokens, or personal data.

## Security and privacy notes

The app accepts text only, limits the request body, and renders notice excerpts as text in the browser. It does not fetch arbitrary URLs, execute submitted content, or call an external AI service. Do not deploy this development server as-is for sensitive or high-traffic production use.
